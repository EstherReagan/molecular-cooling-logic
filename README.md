## Overview

This repository contains the complete source materials for the research paper:

> **Biomimetic Microfluidic Cooling Using Thermo-Responsive Polymers and Iron Redox Couples in Ionic Liquids: A Complete Design, Characterization, and Performance Analysis Framework**

**Authors:** Esther Divya, Reagan Ragnar  
**Affiliation:** Department of Biochemistry (Honours), Independent Research Initiative, Hyderabad, India  
**Corresponding author:** esther.reaganragnar12@proton.me

### Key Contributions

- Passive, chemically responsive cooling fluid that automatically reduces viscosity at thermal hotspots
- 77% viscosity reduction (25 °C → 80 °C) using methylcellulose LCST behaviour
- Thermal response time of 20–300 ms (≈ 2.5–3.3× faster than conventional SCADA)
- Integrated thermogalvanic energy harvesting (≈ 2.36 mW cm⁻²)
- Full material specifications, cost analysis, and 16-week prototype timeline
- All materials are commercially available and non-toxic

## How to Compile the Paper

### Option 1: Overleaf (Recommended)

1. Create a new blank project on [Overleaf](https://www.overleaf.com).
2. Upload `paper/main.tex` and the entire `paper/figures/` folder.
3. Click **Recompile**.

### Option 2: Local LaTeX

```bash
cd paper
pdflatex main.tex
pdflatex main.tex   # run twice for cross-references
```

Required packages: `amsmath`, `booktabs`, `xcolor`, `graphicx`, `mhchem`, `hyperref`, `float`, `caption`, `enumitem`, `microtype`.

## Generating the Figures

All figures were created with the Python script in `scripts/generate_figures.py`.

### Run in Google Colab

1. Open a new Colab notebook.
2. Copy the contents of `scripts/generate_figures.py`.
3. Run the cell — it will generate and zip all 8 figures.

### Run locally

```bash
pip install matplotlib seaborn numpy pandas pillow
python scripts/generate_figures.py
```
